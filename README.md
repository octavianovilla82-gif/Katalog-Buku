# Katalog Buku (Tugas 2 - Sistem Informasi Manajemen Data Sederhana)

PHP murni + MySQL/MariaDB. Fitur: CRUD, login `$_SESSION`, dual bahasa (ID/EN) di `$_SESSION`.

## Cara menjalankan (XAMPP)
1. Salin folder `katalog_buku` ke `htdocs`.
2. Buka phpMyAdmin -> Import `database.sql`.
3. Buka http://localhost/katalog_buku/login.php
4. Login: `admin` / `admin123`

Jika user/password MySQL berbeda, ubah di `config.php`.
